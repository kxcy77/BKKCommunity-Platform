# Open in Xcode

1. Open `BKKCommunity.xcodeproj` in this folder.
2. Select the `BKKCommunity` scheme and an installed iOS 16+ simulator.
3. Configure an Apple team/bundle ID for physical-device testing.
4. Confirm `BKK_API_BASE_URL` points to the intended verified HTTPS `/api/v1` environment.
5. Press Command-R.

The committed API URL points to the verified Railway PHP/MySQL endpoint. Login, reset and RSVP still fail honestly during outages and never manufacture offline success.

Tokens are stored in Keychain. Global cleartext App Transport Security exceptions have been removed.
