# Start Here: BKK Community Platform

## Open the project in Visual Studio Code

1. Unzip this project without changing its folder names.
2. Open `BKKCommunity-Platform.code-workspace` in Visual Studio Code.
3. Read [GETTING_STARTED.md](GETTING_STARTED.md) before running any app.
4. Read [docs/PLATFORM_EXPLAINER_AND_VIVA.md](docs/PLATFORM_EXPLAINER_AND_VIVA.md) to understand the full platform.

## Folder guide

| Folder | Open it when you need to... |
|---|---|
| `apps/android` | Edit or run the Android app in Android Studio |
| `apps/ios` | Edit or run the iPhone app in Xcode |
| `services/web` | Edit or run the PHP website, API and admin dashboard |
| `docs` | Read documentation, visual diagrams, tests and release gates |
| `database-reference` | Review the shared data-model reference |
| `reference` | Study old prototypes only; do not deploy these |

## Before you change code

Create your own Git branch, make one focused change, run the relevant check from the Visual Studio Code task list, then commit your own work with a clear message.
