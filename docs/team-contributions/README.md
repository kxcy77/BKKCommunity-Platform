# Team Contribution Instructions

These files divide small but genuine documentation and testing tasks between the BKK Community Platform group members.

## Important rules

1. Each member must use their own GitHub account.
2. Each member must read and understand the file assigned to them.
3. Test results must remain `NOT TESTED` until the member personally checks the platform.
4. After testing, replace `NOT TESTED` with `PASS`, `FAIL` or `UNAVAILABLE`.
5. Each member must commit only their assigned files.
6. Do not backdate commits or claim tests that were not performed.

## Recommended workflow

1. Pull the latest `main` branch.
2. Create the branch shown in the member's assigned file.
3. Complete the blank dates, devices, browser versions and results.
4. Add genuine screenshots under `docs/evidence/<member-name>/`.
5. Commit the first assigned file.
6. Commit the second assigned file separately.
7. Push the branch and open a pull request.
8. Ask a different group member to review it.
