# Contributing to BKK Community

1. Accept the GitHub invitation using your own account.
2. Create a branch named `feature/your-task` or `fix/your-task`.
3. Make a real, focused change in the area you own.
4. Test the change and include the result in the pull request description.
5. Open a pull request for group review before merging.

Good contributions include accessibility improvements, validated BKK content entry, test cases, documentation corrections, UI fixes, API tests and deployment evidence. A commit should describe the actual change, for example: `Fix event filter empty state`.

Do not amend, backdate, impersonate another contributor or create commits for work you did not do. Git history is the project record and should remain accurate.
